# QUIZ.EXE

A retro monochrome terminal-style quiz game.

## Features

- **10 questions per run** — picked randomly from a local English bank (15 questions built in).
- **Player name required** — enter your name to start.
- **15s timer per question**, score, progress bar, and a high score saved in your browser.

## Usage

Open `index.html` in a browser. Enter your name and press `[ PRESS START ]`.

## Stack

Vanilla HTML / CSS / JavaScript. No build step, no dependencies.
